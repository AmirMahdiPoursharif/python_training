# رمز سزار (Caesar Cipher)

## هدف تمرین

در این تمرین، برنامه‌ای می‌سازیم که متن را با روش **رمز سزار** رمزگذاری و رمزگشایی کند.

رمز سزار یکی از ساده‌ترین روش‌های رمزنگاری است: هر حرف الفبای انگلیسی به اندازه‌ی یک عدد ثابت (کلید) در الفبا جابه‌جا می‌شود. برای نمونه، با کلید `3` حرف `a` به `d`، حرف `b` به `e` و حرف `z` به `c` تبدیل می‌شود.

برنامه ابتدا از کاربر می‌پرسد که می‌خواهد متن را رمزگذاری کند یا رمزگشایی، سپس متن و کلید را دریافت می‌کند و نتیجه را برمی‌گرداند.

قوانین این تمرین:

- فقط حروف انگلیسی (`a-z` و `A-Z`) جابه‌جا می‌شوند.
- حروف بزرگ، بزرگ و حروف کوچک، کوچک باقی می‌مانند.
- سایر کاراکترها مثل فاصله، عدد و علامت‌ها بدون تغییر می‌مانند.
- جابه‌جایی دوره‌ای است؛ پس از `z` دوباره از `a` شروع می‌شود.
- کلید می‌تواند بزرگ‌تر از ۲۶ یا منفی باشد؛ محاسبه با باقی‌مانده‌ی تقسیم بر ۲۶ (`modulo 26`) انجام می‌شود.

## توابع مورد نیاز

### `caesar_cipher(password: str, key: int, decryption: bool = False)`

**محل تعریف:** `caesar_cipher/cryptographer.py`

این تابع منطق اصلی رمز سزار را پیاده‌سازی می‌کند.

الزامات:

- متن را کاراکتر به کاراکتر پیمایش کند.
- حروف بزرگ و کوچک را تشخیص دهد و هر کدام را در محدوده‌ی الفبای خودش جابه‌جا کند.
- برای رمزگشایی، جهت جابه‌جایی را برعکس کند (معادل منفی‌کردن کلید).
- کاراکترهای غیرحرفی را بدون تغییر به نتیجه اضافه کند.
- رشته‌ی نهایی را با `return` برگرداند.

نمونه‌ها:

```python
caesar_cipher("hello", 3)  # "khoor"
caesar_cipher("khoor", 3, decryption=True)  # "hello"
```

### `encrypt(password: str, key: int)`

**محل تعریف:** `caesar_cipher/cryptographer.py`

این تابع پوشش ساده‌ای روی `caesar_cipher()` است و متن را رمزگذاری می‌کند.

نمونه‌ها:

```python
encrypt("abc", 3)  # "def"
encrypt("xyz", 3)  # "abc"
```

### `decrypt(password: str, key: int)`

**محل تعریف:** `caesar_cipher/cryptographer.py`

این تابع پوشش ساده‌ای روی `caesar_cipher()` است و متن رمزگذاری‌شده را با همان کلید رمزگشایی می‌کند.

نمونه‌ها:

```python
decrypt("def", 3)  # "abc"
decrypt("khoor", 3)  # "hello"
```

### `main()`

**محل تعریف:** `caesar_cipher/main.py`

این تابع مسئول اجرای روند اصلی برنامه است.

الزامات:

- پیام خوشامدگویی برنامه را نمایش دهد.
- گزینه‌ی رمزگذاری یا رمزگشایی را از کاربر دریافت کند.
- متن موردنظر و کلید را با `input()` بگیرد.
- کلید را با `int()` به عدد صحیح تبدیل کند.
- تابع مناسب (`encrypt()` یا `decrypt()`) را فراخوانی کند.
- نتیجه را به شکل یک رشته با پیام مناسب برگرداند.
- در صورت اجرای مستقیم فایل، نتیجه‌ی نهایی چاپ شود.

گزینه‌های برنامه:

| گزینه | عملکرد |
| --- | --- |
| `1` | رمزگذاری متن |
| `2` | رمزگشایی متن |

در صورت واردکردن هر گزینه‌ی دیگری، تابع رشته‌ی `Please enter a valid option` را برمی‌گرداند.

## مثال‌های ورودی و خروجی

### مثال اول — رمزگذاری

ورودی:

```text
[1/2]: 1
Enter your text: hello
Enter your key (the key must be an integer and remember it): 3
```

خروجی مورد انتظار:

```text
you encoded text is: 
khoor
```

### مثال دوم — رمزگشایی

ورودی:

```text
[1/2]: 2
Enter your text: khoor
Enter your key (the key is an integer): 3
```

خروجی مورد انتظار:

```text
you decoded text is: 
hello
```

### مثال سوم — گزینه‌ی نامعتبر

ورودی:

```text
[1/2]: 5
```

خروجی مورد انتظار:

```text
Please enter a valid option
```

## تست‌های اصلی

فایل‌های تست این تمرین در پوشه‌ی `caesar_cipher/tests/` قرار دارند:

- `test_cryptographer.py`: تست توابع رمزنگاری و رمزگشایی.
- `test_main.py`: تست روند اجرای برنامه و تعامل با کاربر.

تست‌های `test_cryptographer.py` این موارد را بررسی می‌کنند:

- `test_encrypt`: رمزگذاری حروف کوچک، حروف بزرگ، کاراکترهای غیرحرفی و کلیدهای بزرگ‌تر از ۲۶.
- `test_decrypt`: رمزگشایی متن‌های رمزگذاری‌شده و حالت‌های مرزی مثل کلید `0` و `26`.
- `test_decrypt_reverses_encrypt`: بازگشت متن اصلی با رمزگشایی خروجی رمزگذاری، برای کلیدهای مثبت، منفی و بزرگ.
- `test_non_letter_characters_are_preserved`: بدون تغییر ماندن فاصله، عدد و علامت‌ها.
- `test_case_is_preserved`: حفظ بزرگ یا کوچک بودن هر حرف.
- `test_negative_key_shifts_backwards`: پشتیبانی از کلید منفی.
- `test_empty_text`: رفتار درست با رشته‌ی خالی.
- `test_caesar_cipher_decryption_flag`: عملکرد پارامتر `decryption`.
- `test_key_multiple_of_alphabet_returns_same_text`: بدون تغییر ماندن متن وقتی کلید مضربی از ۲۶ است.

تست‌های `test_main.py` این موارد را بررسی می‌کنند:

- `test_main_encrypts_text`: بازگشت پیام و متن رمزگذاری‌شده در حالت گزینه‌ی `1`.
- `test_main_decrypts_text`: بازگشت پیام و متن رمزگشایی‌شده در حالت گزینه‌ی `2`.
- `test_main_returns_string`: رشته بودن مقدار بازگشتی `main()`.
- `test_main_returns_message_for_invalid_option`: پیام مناسب برای گزینه‌ی نامعتبر.
- `test_main_rejects_unknown_options`: ردکردن گزینه‌های نامعتبر مختلف مثل `0`، رشته‌ی خالی و متن.
- `test_main_displays_intro_message`: نمایش پیام خوشامدگویی و راهنمای گزینه‌ها.
- `test_main_encrypt_then_decrypt_round_trip`: رمزگذاری و سپس رمزگشایی یک متن و بازگشت به متن اصلی.

### اجرای تست‌ها

دستورها را از ریشه‌ی پروژه، یعنی پوشه‌ای که فایل `pyproject.toml` در آن قرار دارد، اجرا کنید.

اجرای تست‌های این تمرین:

```bash
uv run pytest src/007_caesar_cipher -v
```

اجرای یک فایل تست مشخص:

```bash
uv run pytest src/007_caesar_cipher/caesar_cipher/tests/test_cryptographer.py -v
```

اجرای همه‌ی تست‌های پروژه:

```bash
uv run pytest
```
