# بازی سنگ، کاغذ، قیچی (Rock Paper Scissors)

## هدف تمرین

در این تمرین، برنامه‌ای می‌سازیم که بازی سنگ، کاغذ، قیچی را بین کاربر و کامپیوتر اجرا کند.

برنامه یک انتخاب تصادفی برای کامپیوتر تولید می‌کند، انتخاب کاربر را دریافت می‌کند و با استفاده از قوانین بازی، برنده را مشخص می‌کند.

قوانین بازی:

- سنگ، قیچی را شکست می‌دهد.
- قیچی، کاغذ را شکست می‌دهد.
- کاغذ، سنگ را شکست می‌دهد.
- اگر هر دو بازیکن انتخاب یکسانی داشته باشند، بازی مساوی می‌شود.

انتخاب‌های برنامه به این صورت هستند:

| عدد | انتخاب            |
| --- | ----------------- |
| `1` | سنگ (Rock) 🪨     |
| `2` | کاغذ (Paper) 📃   |
| `3` | قیچی (Scissors) ✂ |

## توابع مورد نیاز

### `select_winner(a: int, b: int)`

**محل تعریف:** `rock_paper_scissors/winner_logic.py`

این تابع دو انتخاب را دریافت می‌کند و بر اساس قوانین بازی، برنده را مشخص می‌کند.

الزامات:

- دو عدد مربوط به انتخاب بازیکنان را دریافت کند.
- اگر دو انتخاب برابر باشند، مقدار `None` را برگرداند.
- اگر یکی از انتخاب‌ها برنده باشد، عدد مربوط به انتخاب برنده را برگرداند.
- ترتیب انتخاب‌ها نباید باعث اشتباه در تشخیص برنده شود.

نمونه‌ها:

```python
select_winner(1, 1)  # None
select_winner(2, 1)  # 2
select_winner(1, 2)  # 2
select_winner(3, 2)  # 3
select_winner(1, 3)  # 1
```

در پیاده‌سازی فعلی، این تابع فقط منطق برنده را بررسی می‌کند و اعتبار ورودی‌ها را کنترل نمی‌کند.

### `main()`

**محل تعریف:** `rock_paper_scissors/main.py`

این تابع مسئول اجرای روند اصلی بازی است.

الزامات:

- پیام معرفی بازی را نمایش دهد.
- انتخاب تصادفی کامپیوتر را با استفاده از `random.randint()` تولید کند.
- انتخاب کاربر را با `input()` دریافت کند.
- تابع `select_winner()` را فراخوانی کند.
- نتیجه بازی را به شکل یک رشته برگرداند.
- انتخاب هر دو بازیکن را در پیام نهایی نمایش دهد.
- در صورت اجرای مستقیم برنامه، نتیجه نهایی چاپ شود.

نمونه‌ای از خروجی تابع:

```text
cpu won the game
cpu choice: 📃, human choice: 🪨
```

متن بالا صرفاً نمونه‌ای از خروجی است؛ نتیجه واقعی به انتخاب دو بازیکن بستگی دارد.

## تست‌های اصلی

تست‌های اصلی باید رفتار تابع `select_winner()` و روند اجرای `main()` را بررسی کنند.

موارد مهم برای تست:

- تشخیص صحیح بازی مساوی.
- تشخیص صحیح برنده در هر شش حالت غیرمساوی.
- درست بودن پیام نهایی بازی.
- نمایش نمادهای متناسب با انتخاب هر بازیکن.
- برگرداندن نتیجه از نوع `str` توسط تابع `main()`.
- چاپ پیام معرفی برنامه.
- کنترل انتخاب تصادفی کامپیوتر در تست‌ها.
- شبیه‌سازی ورودی کاربر بدون نیاز به ورود دستی اطلاعات.

### اجرای تست‌های اصلی

از ریشه پروژه، یعنی پوشه‌ای که فایل `pyproject.toml` در آن قرار دارد، اجرا کنید:

```bash
uv run pytest
```

برای اجرای فقط تست‌های اصلی این تمرین:

```bash
uv run pytest src/006_rock_paper_scissors/rock_paper_scissors/tests/test_main.py
```

## چالش‌های پیشنهادی

چالش‌ها برای افزودن قابلیت‌های کوچک به بازی طراحی شده‌اند. لازم نیست قبل از پیاده‌سازی آن‌ها، رفتار فعلی برنامه را تغییر دهید.

### چالش ۱ — بررسی معتبر بودن انتخاب

تابعی به نام `is_valid_choice(choice)` در فایل `winner_logic.py` تعریف کنید.

این تابع بررسی می‌کند که انتخاب واردشده معتبر باشد.

الزامات:

- فقط اعداد صحیح `1`، `2` و `3` معتبر باشند.
- اعداد خارج از این محدوده نامعتبر باشند.
- رشته‌هایی مانند `"1"` و مقادیر `None` معتبر نباشند.
- مقادیر بولی `True` و `False` نیز معتبر محسوب نشوند.
- برای ورودی معتبر، `True` و برای ورودی نامعتبر، `False` برگردانده شود.

راهنمایی: به تفاوت نوع `int` و `str` و همچنین رفتار `bool` در پایتون توجه کنید.

### چالش ۲ — تبدیل عدد به نام انتخاب

تابعی به نام `get_choice_name(choice)` در فایل `winner_logic.py` تعریف کنید.

این تابع عدد انتخاب را به نام انگلیسی آن تبدیل می‌کند.

نمونه‌ها:

```python
get_choice_name(1)  # "rock"
get_choice_name(2)  # "paper"
get_choice_name(3)  # "scissors"
```

الزامات:

- عدد `1` را به `"rock"` تبدیل کند.
- عدد `2` را به `"paper"` تبدیل کند.
- عدد `3` را به `"scissors"` تبدیل کند.
- برای ورودی نامعتبر، خطای `ValueError` ایجاد کند.

راهنمایی: می‌توانید از یک دیکشنری برای نگهداری ارتباط بین اعداد و نام انتخاب‌ها استفاده کنید.

### چالش ۳ — جلوگیری از انتخاب نامعتبر کاربر

پس از پیاده‌سازی `is_valid_choice()`، تابع `main()` را طوری تغییر دهید که ورودی نامعتبر کاربر باعث اجرای اشتباه بازی نشود.

برای مثال، اگر کاربر عدد `5` یا متن `"hello"` را وارد کند، برنامه باید پیام مناسبی نمایش دهد.

راهنمایی:

- پیش از فراخوانی `select_winner()`، ورودی کاربر را اعتبارسنجی کنید.
- به خطای احتمالی تبدیل ورودی با `int()` توجه کنید.
- برای این چالش می‌توانید یک تابع مستقل برای دریافت و اعتبارسنجی انتخاب کاربر بسازید.
