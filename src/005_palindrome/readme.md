# بررسی پالیندروم (Palindrome Checker)

## هدف تمرین

در این تمرین، برنامه‌ای می‌سازیم که بررسی کند آیا یک رشته از ابتدا به انتها و از انتها به ابتدا یکسان خوانده می‌شود یا خیر.

به چنین رشته‌ای **پالیندروم** گفته می‌شود.

مثال‌ها:

- `level` یک پالیندروم است.
- `madam` یک پالیندروم است.
- `python` پالیندروم نیست.

## توابع مورد نیاز

### `check(string: str)`

**محل تعریف:** `palindrome/check_palindrome.py`

این تابع رشته را دریافت می‌کند، نسخه معکوس آن را می‌سازد و بررسی می‌کند که آیا با رشته اصلی برابر است یا خیر.

الزامات:

- رشته را به‌عنوان ورودی دریافت کند.
- با پیمایش از آخر به اول، نسخه معکوس رشته را بسازد.
- رشته معکوس را با رشته اصلی مقایسه کند.
- یک زوج مقدار شامل رشته معکوس و نتیجه بررسی را برگرداند.

برای نمونه، فراخوانی `check("level")` باید نتیجه‌ای معادل زیر داشته باشد:

```python
("level", True)
```

و فراخوانی `check("python")` باید نتیجه‌ای معادل زیر داشته باشد:

```python
("nohtyp", False)
```

### `main()`

**محل تعریف:** `palindrome/main.py`

الزامات:

- پیام معرفی برنامه را نمایش دهد.
- رشته موردنظر را با `input()` از کاربر دریافت کند.
- تابع `check()` را فراخوانی کند.
- بر اساس نتیجه بررسی، پیام مناسب را برگرداند.
- در صورت اجرای مستقیم فایل، نتیجه نهایی چاپ شود.

## تست‌های اصلی

فایل تست‌های اصلی باید رفتار تابع `check()` و در صورت تعریف تست برای آن، رفتار تابع `main()` را بررسی کند.

موارد مهم برای تست:

- تشخیص صحیح پالیندروم.
- تشخیص صحیح رشته غیرپالیندروم.
- درست بودن رشته معکوس برگردانده‌شده.
- درست بودن نوع نتیجه بررسی.
- حفظ قرارداد خروجی تابع.

برای اجرای تست‌های اصلی، از ریشه تمرین استفاده کنید:

```bash
pytest
```

اگر می‌خواهید فقط تست‌های همین تمرین اجرا شوند، مسیر فایل تست اصلی را مشخص کنید؛ برای مثال:

```bash
pytest tests/test_palindrome.py
```

اگر نام یا محل فایل تست شما متفاوت است، مسیر دستور را مطابق ساختار واقعی پروژه تغییر دهید.

## مفاهیم مورد استفاده

- تعریف تابع
- رشته‌ها و اندیس‌گذاری
- پیمایش رشته از آخر به اول
- حلقه `for`
- استفاده از `range()`
- شرط `if`
- مقایسه رشته‌ها
- برگرداندن چند مقدار از تابع
- دریافت ورودی با `input()`
- چاپ خروجی با `print()`
- شرط `if __name__ == "__main__"`
- وارد کردن تابع با `import`
- نوشتن تست با `pytest`

## چالش‌های پیشنهادی

### چالش ۱ — نادیده گرفتن حروف بزرگ و کوچک

بررسی کنید که تفاوت حروف بزرگ و کوچک باعث تغییر نتیجه نشود.

برای مثال، `Level` نیز باید پالیندروم تشخیص داده شود.

**راهنمایی:** پیش از مقایسه، رشته را به یک حالت ثابت مانند حروف کوچک تبدیل کنید.

### چالش ۲ — نادیده گرفتن فاصله‌ها

بررسی کنید که فاصله‌های موجود در متن در نتیجه تشخیص تأثیر نداشته باشند.

برای مثال:

`nurses run`

با نادیده گرفتن فاصله‌ها، یک پالیندروم محسوب می‌شود.

### چالش ۳ — ترکیب چند حالت

رشته‌ای شامل حروف بزرگ و کوچک و فاصله را بررسی کنید. برنامه باید پس از نرمال‌سازی رشته، نتیجه مورد انتظار را تولید کند.

## اجرای تست‌های چالش

فایل تست‌های چالش در مسیر زیر قرار دارد:

`tests/palindrome_challenges.py`

برای اجرای تست‌های چالش به‌صورت دستی، از دستور زیر استفاده کنید:

```bash
uv run pytest src/005_palindrome/palindrome/tests/palindrome_challenges.py
```

این دستور را از ریشه تمرین اجرا کنید؛ اگر فایل در مسیر دیگری قرار دارد، مسیر آن را اصلاح کنید.

چون نام فایل با `test_` شروع نمی‌شود، اجرای معمول `pytest` آن را به‌صورت خودکار کشف نمی‌کند.

**نکته:** پیاده‌سازی فعلی، رشته را به‌صورت دقیق و با در نظر گرفتن حروف بزرگ و کوچک و فاصله‌ها مقایسه می‌کند. بنابراین ممکن است تست‌های چالش مربوط به نرمال‌سازی تا قبل از پیاده‌سازی تغییرات لازم شکست بخورند. این موضوع طبیعی است و نباید باعث تغییر رفتار مورد انتظار تست‌های اصلی شود.

پس از پیاده‌سازی چالش‌ها، می‌توانید نام فایل را به `test_palindrome_challenges.py` تغییر دهید تا در اجرای معمول `pytest` نیز کشف شود.

## نکته مهم

در این تمرین، تابع `check()` مسئول بررسی رشته و برگرداندن نتیجه است؛ تابع `main()` مسئول دریافت ورودی و آماده‌کردن پیام نهایی است.

تست‌های اصلی باید با قرارداد فعلی توابع هماهنگ باشند. چالش‌ها برای افزودن قابلیت‌های جدید هستند و لازم نیست تا قبل از پیاده‌سازی آن‌ها، رفتار فعلی برنامه را تغییر دهید.
