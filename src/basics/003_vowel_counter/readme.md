# &#x20;شمارش حروف صدادار

## هدف تمرین

در این تمرین، با استفاده از رشته‌ها، حلقه `for`، شرط `if` و دیکشنری، برنامه‌ای می‌سازیم که تعداد تکرار حروف صدادار انگلیسی را در متن واردشده توسط کاربر محاسبه کند.

برنامه حروف `a`، `e`، `i`، `o` و `u` را می‌شمارد و نتیجه را در قالب یک دیکشنری برمی‌گرداند.

## تابع مورد نیاز

### `main()`

**محل تعریف:** `vowel_counter/main.py`

این تابع مسئول دریافت متن، شمارش حروف صدادار و برگرداندن نتیجه است.

الزامات:

- پیام معرفی برنامه را نمایش دهد.
- متن را با استفاده از `input()` از کاربر دریافت کند.
- متن را با `lower()` به حروف کوچک تبدیل کند.
- دیکشنری‌ای با کلیدهای `a`، `e`، `i`، `o` و `u` و مقدار اولیه صفر بسازد.
- با استفاده از حلقه `for`، کاراکترهای متن را بررسی کند.
- با شرط `if`، حروف صدادار را تشخیص دهد.
- تعداد هر حرف را در دیکشنری افزایش دهد.
- دیکشنری نهایی را با استفاده از `return` برگرداند.

## تست‌های خودکار

**محل تعریف:** `tests/test_main.py`

تست‌ها تابع `main()` را از فایل `main.py` وارد می‌کنند و موارد زیر را بررسی می‌کنند:

- `test_main_counts_vowels_correctly`: بررسی شمارش صحیح حروف صدادار در یک متن معمولی.
- `test_main_counts_repeated_vowels`: بررسی شمارش حروف صدادار تکراری.
- `test_main_with_no_vowels`: بررسی متن بدون حروف صدادار.
- `test_main_counts_only_lowercase_vowels`: بررسی شمارش حروف صدادار کوچک در ورودی شامل حروف کوچک.
- `test_main_returns_dict`: بررسی نوع مقدار برگشتی.
- `test_main_displays_intro_message`: بررسی نمایش پیام معرفی و درخواست ورود متن.

نام این تست‌ها را تغییر ندهید؛ زیرا مستندات و تست‌های پروژه بر اساس همین نام‌ها تنظیم شده‌اند.

## مفاهیم مورد استفاده

- تعریف و فراخوانی تابع
- دریافت ورودی با `input()`
- رشته‌ها و پیمایش کاراکترها
- تبدیل حروف با `lower()`
- حلقه `for`
- شرط `if`
- دیکشنری و دسترسی به مقادیر با کلید
- افزایش مقدار یک کلید در دیکشنری
- دستور `return`
- دستور `print()`
- شرط `if __name__ == "__main__"`
- وارد کردن تابع با `import`
- شبیه‌سازی ورودی کاربر با `monkeypatch`
- بررسی خروجی چاپ‌شده با `capsys`
- نوشتن تست با `pytest`

## چالش‌های پیشنهادی

### چالش ۱ — بررسی حروف بزرگ و کوچک

بررسی کنید که برنامه بتواند حروف صدادار بزرگ و کوچک را به‌درستی بشمارد.

برای مثال، ورودی `AaEeIiOoUu` باید برای هر یک از حروف صدادار، مقدار `2` را ثبت کند.

**نکته:** این قابلیت در پیاده‌سازی فعلی با استفاده از `lower()` از قبل وجود دارد.

### چالش ۲ — مدیریت ورودی خالی

رفتار برنامه را هنگام دریافت رشته خالی بررسی کنید. خروجی باید دیکشنری‌ای شامل تمام حروف صدادار با مقدار صفر باشد.

### چالش ۳ — محاسبه مجموع حروف صدادار

قابلیتی اضافه کنید که مجموع تمام حروف صدادار موجود در متن را محاسبه کند.

برای نمونه، مجموع حروف صدادار عبارت `Hello World` برابر `3` است.

تلاش کنید این قابلیت را بدون برهم زدن رفتار فعلی تابع `main()` پیاده‌سازی کنید.

## اجرای تست‌های چالش

فایل تست‌های چالش در مسیر زیر قرار دارد:

`tests/vowel_counter_challenges.py`

از آنجا که نام فایل با `test_` شروع نمی‌شود، `pytest` آن را به‌صورت خودکار اجرا نمی‌کند.

برای اجرای تست‌های چالش به‌صورت دستی، از دستور زیر استفاده کنید:

```bash
uv run pytest src/basics/003_vowel_counter/vowel_counter/tests/vowel_counter_challenges.py
```

اگر تست‌ها را به پوشه `tests` منتقل کرده‌اید، دستور را از ریشه پروژه یا مسیری اجرا کنید که مسیر فوق نسبت به آن معتبر باشد.

**نکته:** تست‌های چالش ممکن است تا قبل از پیاده‌سازی قابلیت مربوطه با شکست مواجه شوند. این موضوع طبیعی است و به معنی خراب بودن تست‌های اصلی نیست.

پس از پیاده‌سازی و تکمیل چالش‌ها، می‌توانید نام فایل را به `test_vowel_counter_challenges.py` تغییر دهید تا با اجرای معمول `pytest` نیز کشف و اجرا شود.

## ساختار پیشنهادی پروژه

- `vowel_counter/main.py`: منطق اصلی برنامه.
- `tests/test_main.py`: تست‌های اصلی.
- `tests/vowel_counter_challenges.py`: تست‌های پیشنهادی چالش‌ها که تا زمان آماده‌شدن قابلیت‌های جدید، به‌صورت خودکار اجرا نمی‌شوند.

## نکته مهم

نام تابع `main()` و نوع خروجی آن را حفظ کنید تا تست‌ها بتوانند تابع را مستقیماً فراخوانی کنند.

تست‌های اصلی باید رفتار فعلی برنامه را بررسی کنند و تست‌های چالش برای توسعه قابلیت‌های جدید در نظر گرفته شده‌اند.
