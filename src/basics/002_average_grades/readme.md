# محاسبه میانگین نمره‌ها (Average Grades)

## هدف تمرین

در این تمرین، برنامه‌ای می‌سازیم که نمره‌های واردشده توسط کاربر را دریافت کند و میانگین آن‌ها را محاسبه کند.

کاربر می‌تواند چند نمره وارد کند و پس از پایان ورود نمره‌ها، با وارد کردن `done` یا `d`، محاسبه را به پایان برساند.

مثال:

اگر نمره‌های زیر وارد شوند:

- `10`
- `20`
- `15`

میانگین محاسبه‌شده برابر با `15.0` خواهد بود.

## توابع مورد نیاز

### `main()`

**محل تعریف:** `src/basics/002_average_grades/average_grades/main.py`

این تابع مسئول دریافت نمره‌ها، تشخیص پایان ورودی‌ها و محاسبه میانگین است.

الزامات:

- پیام معرفی برنامه را نمایش دهد.
- با استفاده از `input()` نمره‌ها را از کاربر دریافت کند.
- نمره‌های واردشده را در یک لیست ذخیره کند.
- با استفاده از ساختار `match-case`، ورودی `done` یا `d` را به‌عنوان دستور پایان دریافت نمره‌ها تشخیص دهد.
- نمره‌های ورودی را به نوع `float` تبدیل کند.
- پس از پایان دریافت ورودی‌ها، میانگین نمره‌ها را محاسبه کند.
- مقدار میانگین را با `return` برگرداند.
- در صورت اجرای مستقیم فایل، نتیجه نهایی با `print()` نمایش داده شود.

برای نمونه، اگر نمره‌های `10`، `20` و `15` وارد شوند و سپس کاربر `done` را وارد کند، تابع باید مقدار زیر را برگرداند:

```python
15.0
```

اگر فقط یک نمره مانند `17.5` وارد شود، نتیجه باید همان `17.5` باشد.

- اجرای تست‌ها با `uv`

## چالش‌های پیشنهادی

### چالش ۱ — مدیریت نبودن نمره

بررسی کنید که اگر کاربر بدون وارد کردن هیچ نمره‌ای، دستور `done` یا `d` را وارد کرد، برنامه به‌جای خطای تقسیم بر صفر، پیام مناسبی نمایش دهد.

برای مثال:

```text
No grades were entered
```

در این حالت، تابع باید `None` برگرداند.

**راهنمایی:** پیش از تقسیم مجموع نمره‌ها بر تعداد آن‌ها، بررسی کنید که لیست نمره‌ها خالی نباشد.

### چالش ۲ — مدیریت ورودی غیرعددی

بررسی کنید که اگر کاربر به‌جای نمره، مقداری غیرعددی مانند `abc` وارد کرد، برنامه پیام خطای مناسبی نمایش دهد و دریافت نمره‌ها را ادامه دهد.

برای مثال:

```text
Please enter a valid numeric grade
```

**راهنمایی:** تبدیل ورودی با `float()` ممکن است خطای `ValueError` ایجاد کند. با مدیریت این خطا، می‌توانید از متوقف شدن برنامه جلوگیری کنید.

### چالش ۳ — نادیده گرفتن ورودی نامعتبر

بررسی کنید که ورودی نامعتبر در محاسبه میانگین دخالت نداشته باشد.

برای مثال، اگر ورودی‌ها به ترتیب `abc`، `18` و `done` باشند، میانگین باید برابر با `18.0` باشد.

**راهنمایی:** فقط مقادیری را به لیست نمره‌ها اضافه کنید که با موفقیت به عدد تبدیل شده‌اند.

## اجرای تست‌های چالش

فایل تست‌های چالش در مسیر زیر قرار دارد:

`src/basics/002_average_grades/average_grades/tests/average_grades_challenges.py`

برای اجرای تست‌های چالش، از ریشه پروژه دستور زیر را اجرا کنید:

```bash
uv run pytest src/basics/002_average_grades/average_grades/tests/average_grades_challenges.py
```

برای اجرای تست‌های اصلی و چالش به‌صورت جداگانه، از دو دستور مربوط به هر فایل استفاده کنید.

**نکته:** نام فایل تست‌های چالش با `test_` شروع نمی‌شود؛ بنابراین اجرای معمول `uv run pytest` آن را به‌صورت خودکار کشف نمی‌کند. برای اجرای آن باید مسیر فایل را صریحاً مشخص کنید.

تست‌های چالش ممکن است تا پیش از پیاده‌سازی قابلیت‌های پیشنهادی شکست بخورند. این موضوع طبیعی است؛ تست‌های اصلی باید بدون تغییر باقی بمانند و چالش‌ها برای توسعه تدریجی برنامه هستند.

## نکته مهم

در این تمرین، تابع `main()` هم مسئول دریافت نمره‌ها و هم مسئول محاسبه میانگین است. در نسخه فعلی، ورودی غیرعددی باعث خطای `ValueError` و وارد نکردن هیچ نمره‌ای باعث خطای `ZeroDivisionError` می‌شود.

این رفتارها در تست‌های اصلی فعلی بررسی شده‌اند. هنگام پیاده‌سازی چالش‌ها، تست‌های اصلی را تغییر ندهید؛ قابلیت‌های جدید را به برنامه اضافه کنید و مطمئن شوید که رفتارهای مورد انتظار قبلی همچنان قابل بررسی هستند.
