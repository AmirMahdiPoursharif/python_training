# تمرین: تبدیل دما

## شرح مسئله

برنامه‌ای خط فرمانی بنویسید که بتواند دما را بین دو واحد سانتی‌گراد (Celsius) و فارنهایت (Fahrenheit) تبدیل کند.

برنامه باید ابتدا یک پیام خوشامدگویی نمایش دهد، سپس دمای موردنظر را از کاربر دریافت کند و از او بخواهد واحد فعلی دما را انتخاب کند. در نهایت، دما را به واحد دیگر تبدیل کرده و نتیجه را نمایش دهد.

## الزامات

برنامه باید شرایط زیر را داشته باشد:

1. دمای موردنظر را از کاربر دریافت کند.
2. واحد فعلی دما را از کاربر بپرسد:
   - عدد `1` برای سانتی‌گراد
   - عدد `2` برای فارنهایت
3. دما را به واحد مقابل تبدیل کند.
4. نتیجه تبدیل را به کاربر نمایش دهد.
5. منطق تبدیل دما در توابع جداگانه با نام های ``to_celsius`` و ``to_fahrenheit`` پیاده‌سازی شود.
6. تابع اصلی برنامه مسئول دریافت ورودی‌ها و هماهنگ‌کردن مراحل تبدیل باشد.

## فرمول‌های تبدیل

برای حل مسئله، از روابط ریاضی زیر استفاده کنید:

**تبدیل سانتی‌گراد به فارنهایت**

\[
F = \frac{9}{5}C + 32
\]

**تبدیل فارنهایت به سانتی‌گراد**

\[
C = \frac{5}{9}(F - 32)
\]

در این فرمول‌ها:

- \(C\): دما برحسب سانتی‌گراد
- \(F\): دما برحسب فارنهایت

## مثال‌های ورودی و خروجی

### مثال اول: تبدیل سانتی‌گراد به فارنهایت

ورودی کاربر:

```text
Enter Temperature: 25
Please enter your temperature unit [Celsius/Fahrenheit] 1 / 2: 1
```

خروجی مورد انتظار:

```text
77.0
```

### مثال دوم: تبدیل فارنهایت به سانتی‌گراد

ورودی کاربر:

```text
Enter Temperature: 77
Please enter your temperature unit [Celsius/Fahrenheit] 1 / 2: 2
```

خروجی مورد انتظار:

```text
25.0
```

### مثال سوم: تبدیل دمای منفی

ورودی کاربر:

```text
Enter Temperature: -40
Please enter your temperature unit [Celsius/Fahrenheit] 1 / 2: 1
```

خروجی مورد انتظار:

```text
-40.0
```

## محدودیت‌ها و فرضیات

- ورودی دما یک مقدار عددی معتبر است.
- انتخاب واحد باید عدد صحیح `1` یا `2` باشد.
- برای هر جهت تبدیل، تابع جداگانه‌ای تعریف کنید.
- از تابع ``main`` برای مدیریت جریان اجرای برنامه استفاده کنید.
