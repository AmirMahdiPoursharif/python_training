# تمرین تولید جدول ضرب (Multiplication Table Generator)

## هدف تمرین

در این تمرین، با استفاده از توابع، حلقه‌های تو در تو و لیست‌های تو در تو، برنامه‌ای می‌سازیم که یک جدول ضرب تولید کند.

برنامه اندازه‌ی جدول را از کاربر دریافت می‌کند و جدولی با همان تعداد ردیف و ستون تولید می‌کند. همچنین تابع تولید جدول باید بتواند بدون دریافت اندازه، یک جدول ضرب ۱۰ در ۱۰ بسازد.

## توابع مورد نیاز

### ۱. تابع `multiplication_table(size: int = 10)`

**محل تعریف:** `table_generator.py`

```python
def multiplication_table(size: int = 10):
    ...
```

این تابع جدول ضرب را با اندازه‌ی مشخص‌شده تولید می‌کند و آن را به‌صورت یک لیست تو در تو برمی‌گرداند.

الزامات:

- پارامتر `size` مقدار پیش‌فرض `10` داشته باشد.
- جدول دارای `size` ردیف و `size` ستون باشد.
- مقدار هر خانه برابر حاصل‌ضرب شماره‌ی ردیف و ستون باشد.
- نتیجه با `return` برگردانده شود.

این تابع مستقیماً توسط تست‌های خودکار فراخوانی می‌شود؛ بنابراین نام تابع، نام پارامتر و ساختار خروجی را مطابق مشخصات حفظ کنید.

### ۲. تابع `main()`

**محل تعریف:** `main.py`

```python
def main():
    ...
```

این تابع مسئول اجرای منطق برنامه و تعامل با کاربر است.

الزامات:

- پیام خوشامدگویی را نمایش دهد.
- اندازه‌ی جدول را از کاربر دریافت کند.
- مقدار ورودی را به عدد صحیح تبدیل کند.
- تابع `multiplication_table()` را از ماژول `table_generator` فراخوانی کند.
- جدول تولیدشده را برگرداند تا بخش اجرای اصلی برنامه بتواند آن را نمایش دهد.

### ۳. تست‌های خودکار

**محل تعریف:** `test_table_generator.py`

تست‌ها باید تابع `multiplication_table()` را از فایل `table_generator.py` وارد کنند و موارد زیر را بررسی کنند:

- `test_default_table_size`: بررسی اندازه‌ی پیش‌فرض جدول
- `test_custom_table_size`: بررسی تولید جدول با اندازه‌ی دلخواه
- `test_table_values`: بررسی صحت حاصل‌ضرب‌ها
- `test_table_is_square`: بررسی مربعی بودن جدول

نام این تست‌ها را تغییر ندهید؛ زیرا تست‌های فعلی پروژه با همین نام‌ها هماهنگ شده‌اند.

## اجرای تست‌ها

برای اجرای تمام تست‌های پروژه، از ریشه‌ی پروژه ــ یعنی پوشه‌ای که فایل `pyproject.toml` در آن قرار دارد ــ دستور زیر را اجرا کنید:

```bash
uv run pytest
```

برای اجرای تست‌های همین تمرین، مسیر فایل تست را مشخص کنید:

```bash
uv run pytest src/004_multiplication_table/multiplication_table/test_table_generator.py -v
```

مسیر نمونه را با مسیر واقعی فایل تست در پروژه جایگزین کنید.

## مفاهیم مورد استفاده

- تعریف و فراخوانی تابع
- پارامتر و مقدار پیش‌فرض
- دریافت ورودی با `input()`
- تبدیل نوع داده با `int()`
- حلقه‌های تو در تو (`Nested Loops`)
- لیست‌های تو در تو (`Nested Lists`)
- افزودن عناصر به لیست با `append()`
- بازگرداندن نتیجه با `return`
- ماژول‌ها و دستور `import`
- قالب‌بندی رشته‌ها با `f-strings`
- اجرای مستقیم فایل با `if __name__ == "__main__"`
- تست خودکار با `pytest`

## نکته‌ی مهم

نام و محل توابع مشخص‌شده باید با تست‌ها هماهنگ بماند. می‌توانید پیاده‌سازی داخلی را خودتان بنویسید، اما امضای تابع `multiplication_table(size: int = 10)` و نوع خروجی مورد انتظار آن را تغییر ندهید.

همچنین دقت کنید که `return` نتیجه‌ی تابع را برمی‌گرداند، اما آن را به‌صورت خودکار نمایش نمی‌دهد. برای جلوگیری از چاپ شدن `None` در انتهای خروجی، نحوه‌ی استفاده از `return` و `print()` را در تابع `main()` و بخش اجرای اصلی برنامه به‌درستی مدیریت کنید.
