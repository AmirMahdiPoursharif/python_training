# تمرین تبدیل دما (Temperature Converter)

## هدف تمرین

در این تمرین، برنامه‌ای می‌سازیم که دما را بین دو واحد سانتی‌گراد (Celsius) و فارنهایت (Fahrenheit) تبدیل کند.

برنامه ابتدا دمای موردنظر را از کاربر دریافت می‌کند، سپس واحد فعلی دما را می‌پرسد و در نهایت دما را به واحد مقابل تبدیل کرده و نتیجه را برمی‌گرداند.

## توابع مورد نیاز

### `to_celsius(temperature: float)`

این تابع دمای ورودی را برحسب فارنهایت دریافت می‌کند و آن را به سانتی‌گراد تبدیل می‌کند.

فرمول تبدیل:

[
C = \frac{5}{9}(F - 32)
]

نمونه:

```python
to_celsius(77)  # 25.0
to_celsius(-40)  # -40.0
```

### `to_fahrenheit(temperature: float)`

این تابع دمای ورودی را برحسب سانتی‌گراد دریافت می‌کند و آن را به فارنهایت تبدیل می‌کند.

فرمول تبدیل:

[
F = \frac{9}{5}C + 32
]

نمونه:

```python
to_fahrenheit(25)  # 77.0
to_fahrenheit(-40)  # -40.0
```

### `main()`

این تابع مسئول اجرای روند اصلی برنامه است.

الزامات:

- پیام خوشامدگویی برنامه را نمایش دهد.
- دمای موردنظر را از کاربر دریافت کند.
- واحد فعلی دما را از کاربر بپرسد.
- در صورت انتخاب سانتی‌گراد، تابع `to_fahrenheit()` را فراخوانی کند.
- در صورت انتخاب فارنهایت، تابع `to_celsius()` را فراخوانی کند.
- نتیجه تبدیل را برگرداند یا مطابق ساختار برنامه نمایش دهد.

انتخاب واحدها:

- عدد `1` برای سانتی‌گراد
- عدد `2` برای فارنهایت

## مثال‌های ورودی و خروجی

### مثال اول — تبدیل سانتی‌گراد به فارنهایت

ورودی:

```text
Enter Temperature: 25
Please enter your temperature unit [Celsius/Fahrenheit] 1 / 2: 1
```

خروجی مورد انتظار:

```text
77.0
```

### مثال دوم — تبدیل فارنهایت به سانتی‌گراد

ورودی:

```text
Enter Temperature: 77
Please enter your temperature unit [Celsius/Fahrenheit] 1 / 2: 2
```

خروجی مورد انتظار:

```text
25.0
```

### مثال سوم — تبدیل دمای منفی

ورودی:

```text
Enter Temperature: -40
Please enter your temperature unit [Celsius/Fahrenheit] 1 / 2: 1
```

خروجی مورد انتظار:

```text
-40.0
```

تست‌های این تمرین باید رفتار توابع تبدیل دما و روند اجرای تابع `main()` را بررسی کنند.

موارد مهم برای تست:

- تبدیل صحیح سانتی‌گراد به فارنهایت
- تبدیل صحیح فارنهایت به سانتی‌گراد

- تبدیل دمای صفر
- بررسی دماهایی که نتیجه آن‌ها عدد اعشاری است
- بررسی فراخوانی تابع تبدیل مناسب بر اساس انتخاب واحد
- بررسی نتیجه بازگشتی برنامه
