 ## اجرای برنامه‌ها و تست‌ها

در این پروژه از **uv** برای مدیریت محیط و وابستگی‌های پایتون و از **pytest** برای اجرای تست‌ها استفاده می‌کنیم.

### پیش‌نیازها

قبل از اجرای دستورات، مطمئن شوید Python و uv نصب شده‌اند.

### ۱. باز کردن ترمینال در مسیر پروژه

ترمینال را در پوشه‌ی اصلی پروژه، یعنی پوشه‌ای که فایل `pyproject.toml` در آن قرار دارد، باز کنید.

### ۲. اجرای برنامه

برای اجرای یک فایل پایتون، مسیر آن را از ریشه‌ی پروژه مشخص کنید:

```powershell
uv run python path/to/file.py
```

به‌جای `path/to/file.py` مسیر واقعی فایل موردنظر را وارد کنید.

### ۳. اجرای تست‌ها

برای اجرای تمام تست‌های پروژه:

```powershell
uv run pytest
```

برای اجرای تست‌های یک پوشه‌ی مشخص:

```powershell
uv run pytest path/to/tests/ -v
```

برای اجرای تست‌های یک فایل مشخص:

```powershell
uv run pytest path/to/test_file.py -v
```

در این دستورات، مسیرها را متناسب با محل واقعی فایل‌ها و پوشه‌های پروژه جایگزین کنید.

### ۴. آشنایی با خروجی تست‌ها

- `PASSED`: تست با موفقیت اجرا شده است.
- `FAILED`: تست اجرا شده، اما نتیجه با مقدار مورد انتظار مطابقت ندارد.
- `ERROR`: هنگام آماده‌سازی یا اجرای تست خطایی رخ داده است.
- `collected 0 items`: هیچ تستی برای اجرا پیدا نشده است.

### نکات مهم

- دستورهای بالا را از ریشه‌ی پروژه اجرا کنید، مگر اینکه دستور یا مستندات یک تمرین خلاف آن را مشخص کرده باشد.
- فایل‌های تست معمولاً با پیشوند `test_` نام‌گذاری می‌شوند؛ برای مثال `test_main.py`.
- برای اجرای تست‌ها، باید `pytest` در محیط پروژه نصب شده باشد.
- دستور `uv run` برنامه را در محیط مدیریت‌شده‌ی پروژه اجرا می‌کند و در صورت نیاز، محیط و وابستگی‌های تعریف‌شده را بررسی می‌کند.
- اگر با خطای `ImportError` یا `ModuleNotFoundError` مواجه شدید، مسیر اجرا، ساختار پوشه‌ها و دستورهای `import` را بررسی کنید.
